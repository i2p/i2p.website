I2P 2.14.0(API 0.9.71)이 2026-10-20에 릴리스되었습니다. 이번 릴리스는 router와 번들 앱 전반의 보안을 강화하고, i2psnark 개선 사항을 대규모로 반영하며, 스트리밍 및 tunnel 신뢰성 문제를 수정합니다.

평소와 같이 이 릴리스로 업데이트할 것을 권장합니다. 보안을 유지하고 네트워크에 기여하는 가장 좋은 방법은 최신 릴리스를 실행하는 것입니다.

## 보안

**Router**

- AES 연산과 EdDSA 서명 비교가 이제 상수 시간으로 동작합니다 ([73819404c](https://github.com/i2p/i2p.i2p/commit/73819404c), [6440d5f16](https://github.com/i2p/i2p.i2p/commit/6440d5f16))
- garlic clove 파싱의 범위 초과 읽기와 크기가 부족한 NTCP2 메시지 3 버퍼를 수정했습니다 ([67b2f7327](https://github.com/i2p/i2p.i2p/commit/67b2f7327), [db3cd60f1](https://github.com/i2p/i2p.i2p/commit/db3cd60f1))
- tunnel이 중복 fragment를 버리고 fragment 재조립 맵의 크기를 제한합니다 ([8af94b9e4](https://github.com/i2p/i2p.i2p/commit/8af94b9e4), [4c3d10c12](https://github.com/i2p/i2p.i2p/commit/4c3d10c12))
- NetDB, NTCP, datagram 처리의 소규모 견고성 수정

**i2ptunnel**

- HTTP proxy가 private, loopback 및 link-local IPv4 주소로의 요청을 차단합니다 ([3aef97a9d](https://github.com/i2p/i2p.i2p/commit/3aef97a9d))
- proxy 인증의 SOCKS 4/4a 다운그레이드 우회 문제를 수정했습니다 ([ff63e0cdf](https://github.com/i2p/i2p.i2p/commit/ff63e0cdf))
- HTTP server tunnel이 헤더에서 CR을 제거하며, proxy 인증 문자열은 더 이상 로깅되지 않습니다.
- Hidden Services Manager 전반에 걸쳐 output escaping 수정 사항이 반영되었습니다.

**i2pcontrol**

- CSRF 토큰 보호, JSON 보안 헤더, 인증 실패 시 지연 ([9a1c56f35](https://github.com/i2p/i2p.i2p/commit/9a1c56f35), [e79e4949d](https://github.com/i2p/i2p.i2p/commit/e79e4949d), [8fbfb70fb](https://github.com/i2p/i2p.i2p/commit/8fbfb70fb))
- 기본 `itoopie` 비밀번호로의 폴백 제거

**i2psnark 및 Addressbook**

- 강화된 bencode 파싱(재귀 제한, 중복 키 거부) 및 경로 탐색 검사
- Addressbook이 이제 업데이트 시 destination 불일치를 확인합니다 ([a884b9093](https://github.com/i2p/i2p.i2p/commit/a884b9093))

## i2psnark

- **Magnet 링크:** 이제 모든 tracker가 사용 및 저장되며, `dn` 이름과 `xl` 크기 파라미터 지원이 추가되었습니다
- **Tracker 및 DHT:** UDP 백업 tracker, 더 스마트해진 announce 타이밍, 명세를 준수하는 dictionary 정렬, 압축된 UDP 및 DHT 메시지
- **성능:** torrent 생성 및 재검사 시 메모리 사용량 감소 및 hashing 속도 향상; request throttling, pipelining, 타임아웃 조정
- **UI:** torrent 추가 시 여유 디스크 공간 표시 및 확인, 오디오 재생목록 컨트롤, 탭이 다시 보이면 실시간 업데이트 재개
- **수정:** 시작 검사 후 파일 우선순위가 더 이상 손실되지 않음 ([GH #170](https://github.com/i2p/i2p.i2p/commit/83e4f326f)), metainfo 속성 추출, extension handshake NPE
- BitTorrent v2를 위한 기반 작업 (아직 사용자에게 노출되지 않음)

## 스트리밍 및 전송

- 재전송 및 ack 경로의 스트리밍 동기화 수정과 slow start 및 reset 튜닝 ([061d4e3f6](https://github.com/i2p/i2p.i2p/commit/061d4e3f6))
- tunnel은 주기적으로 5-slot tunnel build 메시지를 사용
- 새로운 명시적 force-IPv6 옵션 추가, Docker bridge 지원은 진행 중
- SAM: DG2/DG3 subsession 수정 ([d2392ae9b](https://github.com/i2p/i2p.i2p/commit/d2392ae9b))
- I2CP: 새로운 `discardMessage()` session API
