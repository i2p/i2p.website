I2P 2.14.0 (API 0.9.71) को 2026-10-20 को जारी किया गया। यह रिलीज़ router और साथ में बंडल किए गए ऐप्स में सुरक्षा को मजबूत करती है, i2psnark में सुधारों का एक बड़ा दौर लाती है, और streaming तथा tunnel विश्वसनीयता संबंधी समस्याओं को ठीक करती है।

हमेशा की तरह, हम अनुशंसा करते हैं कि आप इस रिलीज़ पर अपडेट करें। सुरक्षा बनाए रखने और नेटवर्क की मदद करने का सबसे अच्छा तरीका नवीनतम रिलीज़ चलाना है।

## सुरक्षा

**Router**

- AES operations और EdDSA signature comparison अब constant time हैं ([73819404c](https://github.com/i2p/i2p.i2p/commit/73819404c), [6440d5f16](https://github.com/i2p/i2p.i2p/commit/6440d5f16))
- garlic clove parsing में out-of-bounds read और undersized NTCP2 message 3 buffer को ठीक किया गया ([67b2f7327](https://github.com/i2p/i2p.i2p/commit/67b2f7327), [db3cd60f1](https://github.com/i2p/i2p.i2p/commit/db3cd60f1))
- tunnel duplicate fragments को drop करते हैं और fragment reassembly map पर सीमा लगाते हैं ([8af94b9e4](https://github.com/i2p/i2p.i2p/commit/8af94b9e4), [4c3d10c12](https://github.com/i2p/i2p.i2p/commit/4c3d10c12))
- NetDB, NTCP और datagram handling में छोटे robustness सुधार

**i2ptunnel**

- HTTP proxy निजी, loopback और link-local IPv4 पतों के लिए अनुरोधों को अवरुद्ध करता है ([3aef97a9d](https://github.com/i2p/i2p.i2p/commit/3aef97a9d))
- SOCKS 4/4a में proxy authentication के downgrade bypass को ठीक किया गया ([ff63e0cdf](https://github.com/i2p/i2p.i2p/commit/ff63e0cdf))
- HTTP server tunnels headers से CR हटाते हैं; proxy auth strings अब लॉग नहीं की जातीं
- पूरे Hidden Services Manager में output escaping से जुड़े सुधार

**i2pcontrol**

- CSRF token संरक्षण, JSON सुरक्षा हेडर, और auth विफल होने पर देरी ([9a1c56f35](https://github.com/i2p/i2p.i2p/commit/9a1c56f35), [e79e4949d](https://github.com/i2p/i2p.i2p/commit/e79e4949d), [8fbfb70fb](https://github.com/i2p/i2p.i2p/commit/8fbfb70fb))
- डिफ़ॉल्ट `itoopie` password पर fallback हटाया गया

**i2psnark और Addressbook**

- Hardened bencode parsing (recursion limit, duplicate key rejection) और path traversal checks
- Addressbook अब update पर destination mismatch की जाँच करता है ([a884b9093](https://github.com/i2p/i2p.i2p/commit/a884b9093))

## i2psnark

- **Magnet links:** अब सभी trackers का उपयोग और उन्हें सहेजा जाता है, साथ ही `dn` नाम और `xl` आकार पैरामीटर का समर्थन
- **Trackers और DHT:** UDP backup tracker, बेहतर announce timing, विनिर्देश-अनुरूप dictionary sorting, compressed UDP और DHT संदेश
- **Performance:** torrents बनाते या पुनः जाँचते समय कम memory उपयोग और तेज़ hashing; समायोजित request throttling, pipelining और timeouts
- **UI:** torrents जोड़ते समय free disk space दिखाया और जाँचा जाता है, audio playlist controls, tab के फिर से दिखाई देने पर live updates फिर शुरू हो जाते हैं
- **Fixes:** startup check के बाद file priorities अब खोई नहीं जातीं ([GH #170](https://github.com/i2p/i2p.i2p/commit/83e4f326f)), metainfo attribute extraction, extension handshake NPE
- BitTorrent v2 के लिए आधारभूत कार्य (अभी उपयोगकर्ता-सम्मुख नहीं)

## स्ट्रीमिंग और ट्रांसपोर्ट

- retransmit और ack paths में streaming synchronization के सुधार, साथ ही slow start और reset tuning ([061d4e3f6](https://github.com/i2p/i2p.i2p/commit/061d4e3f6))
- tunnel समय-समय पर 5-slot tunnel build messages का उपयोग करते हैं
- नया explicit force-IPv6 option, Docker bridge support पर काम जारी
- SAM: DG2/DG3 subsessions ठीक किए गए ([d2392ae9b](https://github.com/i2p/i2p.i2p/commit/d2392ae9b))
- I2CP: नया `discardMessage()` session API

## अन्य

- Reseed: reseed2.i2pgit.org, reseed.kiota.ch, दो skhron.eu सर्वर, और i2p.ntp.poweredbyberlin.de जोड़े गए; reseed.i2pgit.org हटाया गया
- Docker: Debian Trixie, OpenJDK 21, Ant 1.10.18, builds में commit SHA अंकित
- izPack 5.2.6, gettext 1.0, और Gradle के लिए build संबंधी सुधार
- GeoIP, Tor blocklist, tracker list, और अनुवाद अद्यतन
