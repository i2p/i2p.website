I2P 2.14.0 (API 0.9.71) se publicó el 2026-10-20. Esta versión refuerza la seguridad en el router y en las aplicaciones incluidas, incorpora una gran tanda de mejoras en i2psnark y corrige problemas de fiabilidad en el streaming y los tunnel.

Como de costumbre, recomendamos que actualice a esta versión. La mejor manera de mantener la seguridad y ayudar a la red es ejecutar la última versión.

## Seguridad

**Router**

- Las operaciones AES y la comparación de firmas EdDSA ahora son de tiempo constante ([73819404c](https://github.com/i2p/i2p.i2p/commit/73819404c), [6440d5f16](https://github.com/i2p/i2p.i2p/commit/6440d5f16))
- Se corrigió una lectura fuera de límites en el análisis de garlic cloves y un búfer demasiado pequeño para el mensaje 3 de NTCP2 ([67b2f7327](https://github.com/i2p/i2p.i2p/commit/67b2f7327), [db3cd60f1](https://github.com/i2p/i2p.i2p/commit/db3cd60f1))
- En los tunnel se descartan fragmentos duplicados y se limita el mapa de reensamblado de fragmentos ([8af94b9e4](https://github.com/i2p/i2p.i2p/commit/8af94b9e4), [4c3d10c12](https://github.com/i2p/i2p.i2p/commit/4c3d10c12))
- Correcciones de robustez menores en NetDB, NTCP y el manejo de datagramas

**i2ptunnel**

- El proxy HTTP bloquea las solicitudes a direcciones IPv4 privadas, de loopback y link-local ([3aef97a9d](https://github.com/i2p/i2p.i2p/commit/3aef97a9d))
- Corregido el bypass de autenticación del proxy mediante degradación a SOCKS 4/4a ([ff63e0cdf](https://github.com/i2p/i2p.i2p/commit/ff63e0cdf))
- Los tunnels del servidor HTTP eliminan CR de las cabeceras; las cadenas de autenticación del proxy ya no se registran
- Correcciones de escape de salida en todo el Hidden Services Manager

**i2pcontrol**

- Protección de token CSRF, cabeceras de seguridad JSON y un retraso en la autenticación fallida ([9a1c56f35](https://github.com/i2p/i2p.i2p/commit/9a1c56f35), [e79e4949d](https://github.com/i2p/i2p.i2p/commit/e79e4949d), [8fbfb70fb](https://github.com/i2p/i2p.i2p/commit/8fbfb70fb))
- Se eliminó el fallback a la contraseña predeterminada `itoopie`

**i2psnark y Addressbook**

- Análisis de bencode reforzado (límite de recursión, rechazo de claves duplicadas) y comprobaciones de path traversal
- Addressbook ahora comprueba la falta de coincidencia de destino al actualizar ([a884b9093](https://github.com/i2p/i2p.i2p/commit/a884b9093))

## i2psnark

- **Enlaces magnet:** ahora se usan y guardan todos los trackers, además de compatibilidad con el parámetro de nombre `dn` y de tamaño `xl`
- **Trackers y DHT:** tracker de respaldo UDP, programación de announce más inteligente, ordenación de diccionarios conforme a la especificación, mensajes UDP y DHT comprimidos
- **Rendimiento:** menor uso de memoria y hashing más rápido al crear o reverificar torrents; ajuste de la limitación de solicitudes, el pipelining y los tiempos de espera
- **UI:** espacio libre en disco mostrado y comprobado al añadir torrents, controles de lista de reproducción de audio, las actualizaciones en vivo se reanudan cuando la pestaña vuelve a estar visible
- **Correcciones:** las prioridades de archivo ya no se pierden tras la comprobación de inicio ([GH #170](https://github.com/i2p/i2p.i2p/commit/83e4f326f)), extracción de atributos de metainfo, NPE en el handshake de extensión
- Preparación para BitTorrent v2 (aún no visible para el usuario)

## Streaming y transporte

- Correcciones de sincronización de Streaming en las rutas de retransmisión y ack, además de ajustes de slow start y reset ([061d4e3f6](https://github.com/i2p/i2p.i2p/commit/061d4e3f6))
- Los tunnel utilizan periódicamente mensajes de construcción de tunnel de 5 slots
- Nueva opción explícita force-IPv6, con soporte para el bridge de Docker en curso
- SAM: corregidas las subsesiones DG2/DG3 ([d2392ae9b](https://github.com/i2p/i2p.i2p/commit/d2392ae9b))
- I2CP: nueva API de sesión `discardMessage()`

## Otro

- SusiDNS: nuevo libro de direcciones "conflicts"
- Reseed: se agregaron reseed2.i2pgit.org, reseed.kiota.ch, dos servidores skhron.eu, e i2p.ntp.poweredbyberlin.de; se eliminó reseed.i2pgit.org
- Docker: Debian Trixie, OpenJDK 21, Ant 1.10.18, SHA del commit marcado en las compilaciones
- Correcciones de compilación para izPack 5.2.6, gettext 1.0 y Gradle
- Actualizaciones de GeoIP, lista de bloqueo de Tor, lista de trackers y traducciones
