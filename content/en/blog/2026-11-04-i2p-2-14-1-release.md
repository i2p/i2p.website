I2P 2.14.1 is released with a fix for a serious bug affecting connectivity.
The outbound NTCP2-PQ handshake did not account for the larger PQ key sizes and would always fail.
The fix will improve connection reliability and netdb stability, especially for lower-bandwidth, non-floodfill routers.

As usual, we recommend that you update to this release.
The best way to maintain security and help the network is to run the latest release.
