This release of I2P, 2.13.0, has been focused on post-quantum support, performance improvements, and bug fixes that improve usability.

Since the 2.12.0 release (April 2026), development has focused on stronger encryption, better bandwidth management, network stability, and a more usable console.

Post-quantum protection is now fully available on the main transport (NTCP2), guarding against future "harvest now, decrypt later" attacks.
The underlying cryptography library has been updated with constant-time operations prevent timing-based attacks.
Legacy transport code (SSU1) has been fully removed.

Tunnels now have per-tunnel bandwidth limits, preventing any single tunnel from monopolizing your connection.
The system is smarter about congestion.

Peer discovery and selection have been tuned for reliability.
Floodfills are tracked more accurately.

The web interface now shows a world map of routers in search results for RouterInfos in the NetDB.

Containers now handle log rotation automatically, drop privileges properly, manage IP addresses correctly in containerized environments, and start up more reliably.

The BitTorrent client (i2psnark) reannounces faster after magnet links resolve, handles edge cases better, and cleans up bandwidth limiters on exit.
The email client (Susimail) offers an experimental standalone build and removes old login code.

As usual, we recommend that you update to this release.
The best way to maintain security and help the network is to run the latest release.
