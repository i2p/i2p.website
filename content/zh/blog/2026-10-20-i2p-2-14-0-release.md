I2P 2.14.0 (API 0.9.71) 于 2026-10-20 发布。此版本加强了 router 及捆绑应用的安全性，带来了大量 i2psnark 改进，并修复了 streaming 和 tunnel 的可靠性问题。

一如既往，我们建议更新到此版本。维护安全并帮助网络的最佳方式是运行最新版本。

## 安全

**Router**

- AES 操作和 EdDSA 签名比较现在为常数时间（[73819404c](https://github.com/i2p/i2p.i2p/commit/73819404c)，[6440d5f16](https://github.com/i2p/i2p.i2p/commit/6440d5f16)）
- 修复了 garlic clove 解析中的越界读取，以及 NTCP2 message 3 缓冲区过小的问题（[67b2f7327](https://github.com/i2p/i2p.i2p/commit/67b2f7327)，[db3cd60f1](https://github.com/i2p/i2p.i2p/commit/db3cd60f1)）
- tunnel 丢弃重复分片，并限制分片重组映射的大小（[8af94b9e4](https://github.com/i2p/i2p.i2p/commit/8af94b9e4)，[4c3d10c12](https://github.com/i2p/i2p.i2p/commit/4c3d10c12)）
- NetDB、NTCP 和 datagram 处理中的若干小型健壮性修复

**i2ptunnel**

- HTTP proxy 阻止对私有、loopback 和 link-local IPv4 地址的请求（[3aef97a9d](https://github.com/i2p/i2p.i2p/commit/3aef97a9d)）
- 修复了 SOCKS 4/4a 降级绕过 proxy 认证的问题（[ff63e0cdf](https://github.com/i2p/i2p.i2p/commit/ff63e0cdf)）
- HTTP server tunnel 会从 header 中剥离 CR；proxy 认证字符串不再被写入日志
- 修复了 Hidden Services Manager 中各处的输出转义问题

**i2pcontrol**

- CSRF token 保护、JSON 安全响应头，以及认证失败后的延迟（[9a1c56f35](https://github.com/i2p/i2p.i2p/commit/9a1c56f35)、[e79e4949d](https://github.com/i2p/i2p.i2p/commit/e79e4949d)、[8fbfb70fb](https://github.com/i2p/i2p.i2p/commit/8fbfb70fb)）
- 移除了回退到默认 `itoopie` 密码的行为

**i2psnark 和地址簿**

- 强化 bencode 解析（递归限制、拒绝重复键）和路径遍历检查
- Addressbook 现在会在更新时检查 destination 不匹配（[a884b9093](https://github.com/i2p/i2p.i2p/commit/a884b9093)）

## i2psnark

- **Magnet 链接：** 现在会使用并保存所有 tracker，并支持 `dn` 名称和 `xl` 大小参数
- **Tracker 与 DHT：** UDP 备用 tracker、更智能的 announce 时机、符合规范的字典排序、压缩的 UDP 和 DHT 消息
- **性能：** 创建或重新校验 torrent 时内存占用更低、哈希更快；优化了请求节流、流水线和超时
- **UI：** 添加 torrent 时显示并检查可用磁盘空间、音频播放列表控制、标签页再次可见时恢复实时更新
- **修复：** 启动检查后文件优先级不再丢失（[GH #170](https://github.com/i2p/i2p.i2p/commit/83e4f326f)）、metainfo 属性提取、扩展握手 NPE
- 为 BitTorrent v2 奠定基础（尚未面向用户）

## 流式传输与传输

- 修复了重传与 ack 路径中的 Streaming 同步问题，并调整了慢启动与重置参数（[061d4e3f6](https://github.com/i2p/i2p.i2p/commit/061d4e3f6)）
- Tunnel 会定期使用 5 槽位的 tunnel 构建消息
- 新增显式的 force-IPv6 选项，Docker 桥接支持正在开发中
- SAM：修复了 DG2/DG3 子会话（[d2392ae9b](https://github.com/i2p/i2p.i2p/commit/d2392ae9b)）
- I2CP：新增 `discardMessage()` 会话 API

## 其他

- SusiDNS：新增“conflicts”地址簿
- Reseed：新增 reseed2.i2pgit.org、reseed.kiota.ch、两台 skhron.eu 服务器以及 i2p.ntp.poweredbyberlin.de；移除 reseed.i2pgit.org
- Docker：Debian Trixie、OpenJDK 21、Ant 1.10.18，构建中嵌入 commit SHA
- 修复 izPack 5.2.6、gettext 1.0 和 Gradle 的构建问题
- 更新 GeoIP、Tor 黑名单、tracker 列表和翻译

完整更新日志：[i2p-2.13.0...i2p-2.14.0](https://github.com/i2p/i2p.i2p/compare/i2p-2.13.0...i2p-2.14.0)
